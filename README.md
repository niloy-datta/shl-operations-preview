# SHL Operations preview

Public static visual demo for the SHL Operations OS interface. The preview is read only: it has no sign-in, API, backend, sample records, or persistent storage.

The full application source remains in the private [shl-operations repository](https://github.com/niloy-datta/shl-operations). This repository contains only the static preview and its GitHub Pages workflow.

## Deploy

GitHub Actions publishes the `site` directory to GitHub Pages after changes to `site/**` are pushed to `main`.
